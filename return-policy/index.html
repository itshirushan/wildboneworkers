Before you order

Return Policy

Orders are purchased through Etsy, so return and exchange requests are handled under the terms shown on the applicable Etsy listing and shop policy.

How to request a return

Please contact WildBoneWorkers through Etsy as soon as possible with your order details and the reason for the request. Do not mail an item back until return instructions have been provided through Etsy.

Current Etsy terms

Return eligibility, the return window and responsibility for return shipping can vary by listing and destination. Check the current Etsy listing before purchasing and again before sending anything back.

Natural variation

Real specimens are natural objects. Size, shape, color, texture and small surface details can vary from specimen to specimen. Please use the listing photographs, measurements and description when evaluating an item.

Damage during delivery

For an item that arrives damaged, contact WildBoneWorkers through Etsy promptly and keep the packaging and photographs of the item and parcel. This helps with an Etsy case or carrier claim when applicable.

Important

This website does not process payments or returns directly. Etsy is the checkout and order-management platform, and its current policies and the applicable listing terms control each order.
