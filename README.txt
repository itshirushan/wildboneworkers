WILD BONE WORKERS — STATIC SEO SITE

Upload this folder to GitHub and connect it to Cloudflare Pages.

Included:
- Home page
- Shop page with category filters
- About page
- 15 individual product pages
- SEO titles/descriptions/canonicals
- Product JSON-LD
- robots.txt
- sitemap.xml
- Responsive CSS

The product photos currently use the public Etsy image URLs for the listings. For the best long-term performance, replace them with optimized copies of your own original product photos.

Etsy remains the source of truth for current price, availability, shipping and checkout.

Prices on the website are currently shown in USD to match the US Etsy shop view.
